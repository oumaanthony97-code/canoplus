# GitHub Pages

This is a static website and does not need a build step.

The root `index.html` is the first landing page. It links to the CANAL+ site at `canalplus.html` and the Canalbox site at `canolbox/index.html`.

To publish it:

1. Upload the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

Keep `landing.css`, `canalplus.html`, the `assets` folder, and the complete `canolbox` folder in their current locations when uploading.

The homepage includes four plan cards based on the supplied July 2025 reference. Confirm current prices with an authorized CANAL+ distributor before publishing them as current offers.
